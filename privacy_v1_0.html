1. Общие положения

Настоящая Политика обработки персональных данных (далее — «Политика») разработана в соответствии с Федеральным законом Российской Федерации от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных пользователей мобильного приложения «Авто Траты» (далее — «Приложение»).

Используя Приложение, Пользователь подтверждает, что ознакомился с настоящей Политикой и даёт добровольное согласие на обработку персональных данных в объёме и целях, указанных в настоящем документе.

Обработка персональных данных осуществляется на принципах: законности, минимальности, целевого использования, локального хранения данных и обеспечения безопасности персональных данных.

2. Категории обрабатываемых персональных данных

2.1. Данные, вводимые Пользователем

Приложение обрабатывает исключительно данные, которые Пользователь вводит самостоятельно:

  • данные об автомобилях (марка, модель, год выпуска, тип топлива и иные характеристики);
  • данные о расходах (сумма, дата, категория, комментарии и связанные поля);
  • данные о пробеге автомобиля;
  • пользовательские категории расходов;
  • текущий выбранный автомобиль;
  • фотографии чеков и/или автомобиля (по инициативе Пользователя).

2.2. Технические и служебные данные

Для обеспечения корректной работы Приложения обрабатываются:

  • локально сгенерированный идентификатор устройства (UUID), используемый исключительно для внутренних нужд Приложения;
  • служебные настройки интерфейса и состояния (SharedPreferences / DataStore);
  • версия, дата и статус согласия на обработку персональных данных (хранится локально);
  • параметры резервного копирования и восстановления;
  • зашифрованные токены и параметры безопасности резервных копий.

PIN-код резервного копирования не хранится в открытом виде и не сохраняется как последовательность цифр.

2.3. Каталог автомобилей

Приложение использует локальный каталог марок и моделей автомобилей, который:

  • хранится в локальной базе данных на устройстве Пользователя;
  • может обновляться путём загрузки файлов с GitHub;
  • не содержит персональных данных Пользователя.

2.4. Фото и файлы

Фотографии и файлы:

  • сохраняются исключительно в app-specific storage Приложения;
  • не передаются Оператору;
  • используются только для функций Приложения (чеки, экспорт, резервное копирование).

3. Разрешения, запрашиваемые Приложением

Приложение запрашивает только те разрешения, которые необходимы для работы его функций:

  • Доступ к сети (INTERNET, ACCESS_NETWORK_STATE) — обновление каталога автомобилей, облачное резервное копирование, открытие страницы политики.
  • Камера (CAMERA) — фотографирование чеков и автомобиля.
  • Доступ к изображениям / галерее (READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE) — выбор изображений Пользователем.
  • Доступ к хранилищу (WRITE_EXTERNAL_STORAGE — для старых версий Android) — экспорт CSV,PDF и Excel файлов.
  • Уведомления (POST_NOTIFICATIONS) — отправка напоминаний и уведомлений, настроенных Пользователем.

Все разрешения запрашиваются исключительно по инициативе Пользователя и используются строго в рамках заявленного функционала.

4. Цели обработки персональных данных

Персональные данные обрабатываются исключительно в следующих целях:

  • предоставление функциональности Приложения;
  • учёт и анализ расходов на автомобиль;
  • отображение статистики и аналитической информации;
  • экспорт данных в PDF и Excel по инициативе Пользователя;
  • отправка уведомлений и напоминаний;
  • создание, восстановление и перенос резервных копий данных;
  • обновление локального каталога автомобилей.

5. Правовые основания обработки

Обработка персональных данных осуществляется на основании:

  • добровольного согласия Пользователя;
  • факта использования Приложения.

6. Сроки обработки и хранения персональных данных

Персональные данные обрабатываются и хранятся в течение всего срока использования Приложения Пользователем.

Персональные данные подлежат удалению:

  • при удалении Приложения с устройства Пользователя;
  • либо при достижении целей обработки персональных данных.

Обработка персональных данных прекращается автоматически при прекращении использования Приложения.

7. Хранение и передача персональных данных

7.1. Локальное хранение

Все персональные данные Пользователя хранятся исключительно локально на устройстве Пользователя.

  • Оператор не осуществляет централизованное серверное хранение персональных данных;
  • Оператор не имеет доступа к данным Пользователя;
  • Оператор не использует собственные информационные системы персональных данных.

7.2. Резервное копирование

Локальное резервное копирование

  • осуществляется исключительно по инициативе Пользователя;
  • сохраняется в памяти устройства;
  • может быть зашифровано;
  • предназначено для восстановления данных и переноса на другое устройство.

Облачное резервное копирование (Яндекс.Диск)

  • осуществляется только по инициативе Пользователя;
  • требует авторизации Пользователя в сервисе Яндекс.Диск;
  • резервная копия хранится в папке приложения на Яндекс.Диске;
  • данные передаются и хранятся в зашифрованном виде;
  • Оператор не имеет доступа к содержимому резервных копий.

Облачное резервное копирование может быть отключено Пользователем в настройках Приложения.

7.3. Сетевые взаимодействия

Приложение может обращаться только к следующим ресурсам:

  • сервисы авторизации и API Яндекс.Диска;
  • GitHub (загрузка файлов каталога автомобилей);
  • страница политики конфиденциальности Приложения.

Передача персональных данных третьим лицам не осуществляется, за исключением случаев, прямо инициированных Пользователем для выполнения функций Приложения.

8. Безопасность персональных данных

Для защиты персональных данных используются:

  • системные механизмы безопасности Android;
  • Android Keystore;
  • криптографическое шифрование резервных копий;
  • биометрическая аутентификация (по желанию Пользователя).

9. Системный резервный бэкап Android

Приложение поддерживает системный механизм резервного копирования Android (Auto Backup / Device Transfer) в рамках настроек операционной системы устройства Пользователя.

10. Права Пользователя

Пользователь имеет право:

  • использовать Приложение без регистрации и создания учётной записи;
  • отказаться от предоставления необязательных разрешений;
  • отключить резервное копирование;
  • удалить все данные путём удаления Приложения с устройства.

11. Изменение Политики

Оператор вправе вносить изменения в настоящую Политику. Актуальная версия Политики всегда доступна в Приложении.

12. Контактная информация
