1. Общие положения

Настоящая Политика обработки персональных данных (далее — «Политика») разработана в соответствии с Федеральным законом Российской Федерации от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных пользователей мобильного приложения «Авто Траты» (далее — «Приложение»).

Используя Приложение, Пользователь подтверждает, что ознакомился с настоящей Политикой и даёт согласие на обработку персональных данных в объёме и целях, указанных ниже.

Обработка персональных данных осуществляется на принципах законности, минимальности, целевого использования и обеспечения безопасности данных.

2. Категории обрабатываемых персональных данных

2.1. Данные, вводимые Пользователем

  • данные об автомобиле (марка, модель, год выпуска, тип топлива и иные характеристики);
  • данные о расходах (суммы, даты, категории, комментарии);
  • данные о пробеге автомобиля;
  • пользовательские категории расходов;
  • фотографии чеков и автомобиля (по желанию Пользователя).

2.2. Технические данные

  • технический идентификатор, используемый для работы уведомлений (push-токен);
  • служебные данные приложения, необходимые для корректной работы функций.

Push-токен используется исключительно для доставки уведомлений и не применяется для идентификации личности Пользователя или анализа его поведения.

Доступ к камере, файловой системе и уведомлениям запрашивается только по инициативе Пользователя и используется исключительно для соответствующих функций Приложения.

Приложение не осуществляет сбор данных о геолокации, контактах, телефонных вызовах, содержимом сообщений и иных данных, не относящихся к функциональности Приложения.

3. Цели обработки персональных данных

Персональные данные обрабатываются исключительно в следующих целях:

  • предоставление функциональности Приложения;
  • учёт и анализ расходов на автомобиль;
  • отображение статистики и аналитической информации;
  • экспорт данных в формат CSV по инициативе Пользователя;
  • отправка уведомлений и напоминаний, настроенных Пользователем;
  • создание и восстановление локальных резервных копий данных.

4. Правовые основания обработки

Обработка персональных данных осуществляется на основании добровольного согласия Пользователя, выраженного при использовании Приложения.

5. Хранение и передача персональных данных

Все персональные данные Пользователя хранятся локально на устройстве Пользователя. Оператор не осуществляет централизованное хранение персональных данных на серверах.

5.1. Локальное резервное копирование

  • резервное копирование осуществляется исключительно по инициативе Пользователя;
  • резервная копия представляет собой локальный файл на устройстве Пользователя;
  • Пользователь самостоятельно выбирает место хранения резервной копии;
  • Оператор не имеет доступа к содержимому резервных копий;
